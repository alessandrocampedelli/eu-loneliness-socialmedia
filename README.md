## Description

This repository contains the Python code used to analyse the association between social media use intensity and perceived loneliness among European adults, focusing on the moderating role of age.

The analysis is based on the **EU Loneliness Survey 2022** (EU-LS 2022), produced by the European Commission's Joint Research Centre (JRC), with 25,646 observations across the 27 EU countries.

## How to run the code

### 1. Clone the repository

```bash
git clone https://github.com/MatteMito/eu-loneliness-socialmedia.git
cd eu-loneliness-socialmedia
```

### 2. Install the dependencies

```bash
uv sync
```

`uv` reads `pyproject.toml` and `uv.lock`, creates a virtual environment automatically and installs every dependency in the exact version used during development.

### 3. Start Jupyter

```bash
uv run jupyter notebook eu-loneliness-socialmedia.ipynb
```

### 4. Run the cells in order

The notebook is organised in sequential steps. **Cells must be run in order**, because each step uses the output of the previous one:

| Step | Content | Output |
|---|---|---|
| **Step 1** | Loading, cleaning and preparing the variables | `output/dataset/eu_ls_clean.csv` |
| **Step 2** | Exploratory data analysis (EDA), Pearson and Spearman correlations | EDA figures |
| **Step 3** | Linear OLS regression by age group, interaction F-test, non-linearity analysis for ages 16–34 | OLS figures + forest plot |
| **Step 4** | Random Forest, permutation importance, Partial Dependence Plot | PDP figures |

To run the whole notebook at once: **Kernel → Restart & Run All**.

## Main variables

| Variable | Type | Description |
|---|---|---|
| `score_UCLA` | Numeric (3–9) | Dependent variable: sum of the 3 UCLA items on perceived loneliness |
| `intensita_sm` | Ordinal (1–8) | Independent variable: daily time spent on social media |
| `fascia_eta` | Categorical | Age group: `16–34`, `35–54`, `55+` |
| `sesso` | Binary | Respondent's gender |
| `education` | Ordinal (ISCED) | Education level |
| `income` | Ordinal (1–10) | Income decile within the national distribution |
| `paese` | Categorical (1–27) | EU country (used as a fixed effect in the models) |

## Key findings

- The correlation between social media use intensity and perceived loneliness is **positive and significant** in every age group (p < 0.001).
- The effect is strongest in the **35–54** group (β = +0.126), almost the same in the **16–34** group (β = +0.114), and weaker in the **55+** group (β = +0.075).
- In the **16–34** group there is a non-linear acceleration concentrated at the highest levels of use (6–8), independently confirmed by the Random Forest PDP.
- OLS and Random Forest agree on the direction, the shape and the age gradient of the effect.
